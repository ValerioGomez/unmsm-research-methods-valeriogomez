1. Project Overview

This capstone project develops a fully reproducible, end-to-end machine learning pipeline to predict the ecological growth habit — Tree, Shrub, Herb, or Liana — of medicinal plants in the Peruvian Amazon, using data compiled by the Instituto de Investigaciones de la Amazonía Peruana (IIAP) over 18 years (~1,028 unique records across Loreto, Ucayali, and Madre de Dios).

Why does this matter? Identifying plant growth habits in the field requires specialized botanical expertise and significant time. An automated ML classifier can assist IIAP researchers in auditing database records, identifying cataloging errors, and accelerating ecological surveys of the Amazon's hyper-diverse medicinal flora.

Research Questions

IDResearch Question
GQIs it possible to predict the growth habit (Tree, Shrub, Herb, Liana) of Peruvian Amazonian medicinal plants using taxonomic, geographic, and ethnobotanical features with machine learning?
SQ1What is the performance (Accuracy, Macro F1-score) of Logistic Regression, Random Forest, and XGBoost?
SQ2Which features (Family, Genus, Department, or Ethnobotanical Uses) contribute the most?
SQ3Which feature strategy (Taxonomic only → +Geographic → +TF-IDF Text) yields the best performance?
SQ4Are there significant performance differences when predicting different growth habit classes?

Hypotheses

  • H₀: ML models cannot outperform a random baseline classifier on this task.
  • H₁: ML models can achieve a Macro F1-score > 0.70.
  • H₂: Ensemble methods (XGBoost, Random Forest) will outperform Logistic Regression due to high-dimensional taxonomic and TF-IDF features.

2. Approach Followed

15-Session Learning Trajectory

2.1 Research Paradigm (Session 1–2)

The study is anchored in a Realist ontology (growth habits are objective, physical facts) and a Positivist epistemology (knowledge validated through empirical observation and reproducible metrics). The methodology is quasi-experimental: we apply computational controls (fixed random seed SEED=42, stratified partitioning) to retrospective observational data, simulating the rigor of a laboratory experiment.

2.3 Machine Learning Pipeline (Session 5)

The pipeline follows a strict no-leakage architecture: all preprocessing transformers are fit exclusively on training data.

StepImplementation
1. Data VersioningDVC tracks dataset.csv (1,028 records) via Google Drive remote. Raw and processed files have complete lineage.
2. Train / Val / Test SplitStratified 70% / 15% / 15% using SEED=42 before any feature engineering.
3. Feature Engineering (ColumnTransformer)
  • Taxonomic (Family, Genus): OneHotEncoder(handle_unknown='ignore')
  • Geographic (Distribution): CountVectorizer (comma-tokenized dept. codes)
  • Ethnobotanical text (Uses): TfidfVectorizer(max_features=300)
4. Models ComparedMultinomial Logistic Regression · Random Forest (100 trees) · XGBoost (100 estimators)
5. Experiment TrackingMLflow logs all hyperparameters, Accuracy, Macro F1, and model artifacts per run.
6. ContainerizationDockerfile freezes Python 3.11 + all pinned dependencies (requirements.txt).

Reproducibility standard: Any researcher can clone the repository, run dvc pull to retrieve the dataset, and docker build + docker run to reproduce identical results — the "Stranger Test."

2.4 Ethics & Integrity (Sessions 9–12)

  • Belmont Principles applied to Ethnobotany: Respect for indigenous community autonomy; beneficence through open conservation tools; justice by keeping research benefits within Peru (UNMSM / IIAP).
  • Nagoya Protocol compliance: No intellectual property claims on traditional knowledge; dataset custody maintained by IIAP; code shared under MIT license.
  • Bias Audit: Geographic disparate impact analysis revealing Loreto overrepresentation (52% of records) causes significantly lower recall for plants from Ucayali and Madre de Dios.
  • Retracted Paper Analysis: Case study of fabricated 99.8% validation accuracy in a CNN study — demonstrating why honest test-set reporting matters.

2.5 Protocol Versions & Peer Review (Sessions 13–15)

  • Protocol v0.1 (Session 3): Initial outline — problem statement, objectives, timeline.
  • Protocol v1.0 (Session 13): Complete draft with hypotheses, preliminary results, and quasi-experimental design.
  • Peer Review (Session 14): Three reviewers evaluated scientific rigor, reproducibility, ethical compliance, clarity, and feasibility. All three recommended Accept with Minor Revisions.
  • Protocol v2.0 (Session 15): Final protocol integrating all reviewer feedback with a formal response table.

3.3 Reproducibility Audit Outcome (Session 6)

An external botanical ML paper (Muflih et al., 2024) was audited against 6 reproducibility criteria. The paper scored 1/10 — failing on random seeds, data availability, software versions, leakage prevention, and statistical confidence reporting. This validated the design philosophy of this capstone project as a direct methodological counterpoint to prevailing practices in the field.

4. Challenges Encountered

#ChallengeHow It Was Addressed
1 High-dimensionality vs. small sample size
Combining 300 TF-IDF features + OHE taxonomic/geographic features creates a >350-column feature matrix on only 70 training samples, causing ensemble models to overfit.		 Reported honestly. Added Logistic Regression (L₂-regularized) as a parametric baseline. Full-scale re-evaluation on 1,028 records identified as primary next step.
2 Geographic sampling bias
Loreto represents 52% of the database due to IIAP's historical institutional presence in Iquitos, skewing model performance against Ucayali and Madre de Dios plants.		 Documented in the Bias Audit Report. Proposed inverse-frequency sample weighting as a mitigation strategy for the next pipeline iteration.
3 Ethnobotanical text in Spanish
The USOS field contains unstructured Spanish descriptions with regional vocabulary, abbreviations, and non-standardized terminology, reducing TF-IDF signal quality.		 Applied basic tokenization and stopword removal. Identified lemmatization and Spanish-specific NLP (SpaCy es_core_news_sm) as a future enhancement.
4 Ethics of traditional knowledge in open science
Standard open science mandates full data sharing, but raw ethnobotanical data represents 18 years of indigenous community knowledge — conflicting with open science norms.		 Resolved through the Nagoya Protocol compliance framework: code is MIT open-source, but dataset redistribution remains under IIAP academic custody.
5 Taxonomic multicollinearity
Including all taxonomic ranks (Group, Class, Order, Family, Genus) introduces deterministic redundancy (higher ranks are mathematically derivable from Genus), inflating model complexity.		 Resolved in Session 1 based on literature (Brown et al., 2021): only Family and Genus are included as taxonomic features.

6. Concise Research Summary

One-paragraph summary (suitable for oral presentation opening):

This study asks a simple but scientifically significant question: Can a machine learning model predict how a medicinal plant grows in the Peruvian Amazon — whether it is a Tree, Shrub, Herb, or Liana — based only on its taxonomic family and genus, the departments where it has been recorded, and the traditional descriptions of how indigenous communities have used it for centuries? Using a dataset of over 1,000 plants compiled by the IIAP across 18 years, we built and compared three classifiers — Logistic Regression, Random Forest, and XGBoost — within a fully reproducible pipeline that locks random seeds, versions data with DVC, tracks experiments with MLflow, and freezes the computational environment with Docker. The models achieved validation Macro F1-scores of up to 0.83, confirming the feasibility of this prediction task, though honest test-set evaluation revealed overfitting challenges that will be resolved by scaling to the full 1,028-record dataset. Beyond performance, this project documents the ethical complexities of applying AI to traditional indigenous knowledge, demonstrates reproducibility standards that contrast sharply with the broader botanical ML literature, and provides IIAP with an open-source tool for automated flora cataloging.
