# AI Use Policy: Responsible Integration of Generative AI

**Project:** Growth Habit Classification of Peruvian Amazonian Medicinal Plants using Machine Learning  
**Author:** Valerio Gomez  
**Course:** Research Methods & Scientific Integrity in AI (UNMSM)

---

## 1. Allowed and Permitted Uses of Generative AI

Generative AI tools (including large language models like Claude, GPT-4, and GitHub Copilot) are integrated into this project under strict boundaries to assist in mechanical and technical tasks:

* **Code Debugging & Optimization:** Using AI to troubleshoot syntax errors in Python scripts, optimize Pandas data operations, or write standard Scikit-learn preprocessing wrappers.
* **Structuring & Formatting:** Using AI to format Markdown files, generate templates for protocols and model cards, or compile Git ignore rules.
* **Translation & Copyediting:** Since the course requires all production code and documentation to be written in English, AI is utilized to translate draft ideas from Spanish and correct grammatical structure and spelling.

---

## 2. Prohibited and Unacceptable Uses of Generative AI

To preserve scientific integrity, AI tools are strictly banned from the following tasks:

* **Data Falsification or Augmentation:** AI shall not be used to fabricate plant records, fill in missing values synthetically, or generate dummy columns to improve model accuracy.
* **Plagiarism & Faked Citations:** AI shall not be used to write the literature review segments from scratch or invent DOIs/references. All cited publications must be read and verified by the author.
* **Deceptive Authorship:** AI shall not write the core scientific analysis, discussions, or conclusions of the research. These must reflect the independent intellectual contribution of the researcher.

---

## 3. Researcher Declaration and Accountability

As the principal investigator of this study, I, **Valerio Gomez**, declare that:
1. I am fully accountable for the accuracy, truthfulness, and scientific integrity of all code, datasets, metrics, and text presented in this repository.
2. Every line of code generated with AI assistance was reviewed, tested, and validated for correctness.
3. No text in the final research protocols was copied directly from AI outputs without intellectual modification and citation checks.
